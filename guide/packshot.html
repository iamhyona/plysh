01일러스트 스트럭처

디자인을 얹기 전에 구성품 크기·수량·위치·여백만으로 구조를 먼저 결정.

구성품·아트보드 준비

  • 전체 구성품을 실제 사이즈(mm)로, 흰색 면 + 검정 스트로크로 일러스트 파일 하나에 모두 그리기.
  • 팩샷에 노출할 이미지 수량만큼 구성품을 복제해 준비.
  • 아트보드는 3:4 비율로 설정.
  • 구성품끼리의 실제 크기 비율을 유지하며 배치.
  • 타이틀·로고 위치와 텍스트가 들어갈 공간도 이 단계에서 결정. 로고가 겹치거나 필요 없으면 빼거나 줄이는 것도 검토.
  • 맨 아래 푸터에는 소속사·사운드웨이브 로고와 리갈이 들어감.
3:4 아트보드 안에 프로젝트 타이틀명·공식 표기명(보라 영역) → 구성품 → 푸터(주황 영역) 순서. 구성품은 실제 크기 비율대로 흰 면 + 검정 선으로만 그리고, 이름·사이즈·수량 자리를 함께 잡기. 푸터에는 소속사·사운드웨이브 로고와 리갈이 들어감.

노출 수량 기준

구성품준비할 이미지
포토카드멤버별 전체 수량 + 앞뒷면
캘린더표지 + 사진면 + 달력면
포토북표지 + 대표 스프레드 1~2개
기타앞뒷면과 보여줄 디테일

시작 전 꼭 확인

작년 해당 소속사 아티스트의 팩샷·상세페이지를 반드시 참고하고, 아래 특이사항을 확인.

  • 팩샷 타이틀·로고를 쓰는지
  • 구성품명·사이즈·수량 텍스트를 생략하는지
  • 포토북·캘린더 내지를 몇 장 보여주는지
  • 포토카드 뒷면을 보여주는지
  • 리갈·안내 문구를 표기하는지
주의 이 단계에서는 디자인이나 목업 효과 없이 배치와 구조만 확인. 구성품은 각도를 비틀지 말고 정면으로 똑바로 배치.
1차 컨펌일러스트 스트럭처 공유 → 배치·노출 구성 확정 후 포토샵 진행

02포토샵 팩샷 목업

작업 파일 설정

아트보드3:43000 × 4000 px
컬러RGBsRGB IEC61966-2.1

고해상도로 작업한 뒤 소속사 전달용 사이즈로 줄이기.

주의 작은 판형에서 작업하면 텍스트와 이미지 효과 품질이 떨어질 수 있음. 고해상도를 유지.

최종 이미지 준비

인디자인 확인최종 디자인 파일 확인
JPG 내보내기페이지별 JPG 300ppi, 펼침면은 스프레드
스트럭처 가져오기확정한 스트럭처를 포토샵으로
같은 배율로 배치모든 JPG를 같은 배율(%)로 축소·배치

스마트 오브젝트 관리

  • 모든 구성품은 개별 스마트 오브젝트로 작업.
  • JPG를 끌어다 놓으면 스마트 오브젝트가 생기지만, 한 번 더 스마트 오브젝트로 변환해 중첩 구조로 관리.
  • 나중에 이미지 교체, 블러, 레이어 추가를 할 수 있게 만들어 두기.
스마트 오브젝트 · 목업 효과·그림자·블러를 여기에
스마트 오브젝트 · 이미지 교체·레이어 추가
JPG 원본 (인디자인에서 내보낸 300ppi)
겉 스마트 오브젝트 안에 JPG 스마트 오브젝트를 한 겹 더
주의 JPG 스마트 오브젝트를 그대로 두지 말고 편집할 수 있는 레이어 구조로 관리. 병합(플랫) 금지.

블러 버전

  • 블러 버전은 작게 줄였을 때도 인물을 알아보기 어려울 정도로 강도를 강하게 주는 것이 최근 추세.
  • 구성품 하나에 먼저 적용해 블러 강도를 확인한 뒤, 같은 강도로 전체에 적용하는 것을 권장.

MD 구성품 강조·배경 컬러

  • MD 구성품은 부각되게 배치. 너무 구석에 두지 말고, 실사이즈보다 조금 크게 키워 강조.
  • 팩샷 배경 컬러는 구성품들과 명도·채도가 비슷해 묻히지 않도록 대비 있게 설정.
배경은 구성품 컬러와 명도·채도 차이를 두고, MD 구성품은 실사이즈보다 조금 키워 눈에 띄는 자리에
주의 포토카드·엽서 등은 구성품 수가 아주 많지 않으면 너무 촘촘하게 겹쳐 배치하지 않기.

03팩샷 레이아웃·정보 표기

가로로 나란히 놓을 때

a 구성품 사이 간격 같게 · b 구성품과 텍스트 사이 간격 같게 · 이름은 굵게, 사이즈·수량은 작게

위아래 두 줄로 놓을 때

위아래 두 줄일 때 · 줄마다 하단을 맞추고 왼쪽 끝선을 통일 · c 윗줄 텍스트와 아랫줄 구성품 사이 간격은 줄마다 같게 · a 가로 간격은 윗줄·아랫줄 모두 같게

배치·정렬

  • 상·하단, 좌·우 끝선, 중앙 등 정렬 기준을 통일.
  • 구성품 사이 간격과 여백을 일정하게 유지.
  • 구성품 아래 그림자 때문에 하단 텍스트가 좁아 보이면 간격을 더 띄워서 눈으로 보정.
한 팩샷 안에서는 정렬 기준을 하나로 통일 · 구성품 아래 그림자가 있으면 텍스트와의 간격을 그림자만큼 더 띄우기

구성품 정보 표기

  • 가능하면 팩샷 아래에 구성품명 · 사이즈 · 수량을 표기.
  • 구성품명과 사이즈·수량은 글자 크기나 굵기로 위계 구분.
  • 텍스트가 너무 작아지지 않게 가독성 확보.
  • 구성품과 해당 텍스트 사이 간격을 통일.
이름 → 사이즈·수량 순서로 위계를 나누고, 구성품과 텍스트 사이 간격(b)은 모두 같게
주의 그림자나 형태 때문에 실제 간격이 같아도 다르게 보일 수 있음. 눈으로 보고 보정.
2차 컨펌팩샷 목업·정보 표기 완료 후 공유 → 전체 구성 확정

04구성품 요약·상세페이지

CONTENTS (구성품 요약)

  • 팩샷 + 상세페이지로 이어 붙일 때, 팩샷 바로 다음에 전체 구성품을 텍스트로 한 번 더 요약하는 CONTENTS 영역을 넣기. 일반 팩샷만 전달할 때는 넣지 않음.
  • 구성품명과 수량을 간결하게 정리.
  • 팩샷에서 상세페이지로 넘어가는 흐름을 나눠주는 역할.
  • 푸터(소속사·사운드웨이브 로고 + 리갈)는 상세페이지 맨 마지막에 배치.

상세페이지 구성

  • 구성품 이미지 → 그 구성품의 상세 정보 → 다음 구성품 이미지 → 상세 정보 순서로 반복.
  • 구성품과 설명 텍스트 사이 간격은 통일하고, 다른 구성품 영역 사이에는 충분한 여백 확보.
  • 설명이 바로 위 구성품의 정보로 읽히게 배치. 여백만으로 구분이 어려우면 얇은 구분선 사용.
주의 텍스트가 위아래 어느 구성품의 정보인지 헷갈리지 않도록 여백과 구분 기준을 꼭 확인.
3차 컨펌상세페이지 전체 레이아웃 완료 후 공유 → 수정 사항 확인

05최종 검수·파일 저장

구성·디자인

  • 구성품·이미지 누락 없음
  • 최종 디자인 이미지 적용
  • 구성품별 사이즈·수량 정확
  • 정렬·여백·텍스트 가독성
  • 푸터의 소속사·사운드웨이브 로고, 리갈·안내 문구 누락 없음 (이미지와 실제 제품이 다를 수 있다는 안내 등 소속사별 필수 표기)

파일

  • PSD 안 스마트 오브젝트·레이어 수정 가능
  • RGB / sRGB IEC61966-2.1 설정
  • 최종 JPG·PNG 내보낼 때 sRGB 프로파일 포함
  • 전달용 파일 사이즈·이미지 품질 확인
주의 CMYK, Adobe RGB 등 다른 컬러 프로파일로 저장 금지.

텍스트·표기 기준

  • 오탈자와 띄어쓰기를 확인.
  • 구성품명, 사이즈, 수량, 단위 표기 방식을 페이지 전체에서 통일.
  • 작년도 해당 소속사 작업물의 표기 기준을 반드시 확인. 표기에 오류가 있으면 수정안을 제안하고 확인 요청.
확인할 표기예시
구성품 영문 표기PHOTOCARD / PHOTO CARD / Photocard · PHOTOBOOK / PHOTO BOOK (띄어쓰기·대소문자)
수량 단위PC / pc · EA / ea · PCS / EA (단위 종류와 대소문자)
숫자 + 단위100mm / 100 mm (사이 띄어쓰기 여부)
이렇게100 × 150 mm곱하기는 곱하기 기호 ×
이렇게 하지 않기100 x 150 mm · 100X150mm알파벳 x, X 사용
주의 일반 맞춤법과 별개로 소속사마다 고유 표기 방식이 있을 수 있음. 임의로 고치지 말고 작년도 작업 기준을 먼저 확인.
